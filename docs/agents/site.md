# Site

The one-step installer and the brand files served by the site.

- `site/install.sh` (POSIX sh) and `site/install.ps1` (ASCII, errors thrown instead of `exit` so `irm | iex` keeps the window): the one-step installer served by the site. They check Node 22+, npm and git without installing them, refuse an existing folder that is not a clone of the repo (a clone is updated with `pull --ff-only`), ask `[s/N]` (from /dev/tty on Unix) before cloning, `npm ci`, `npm run build` and writing the `zero` command in the user's folders (user PATH only on Windows), then launch `zero setup`. `test/installer.test.ts` checks them.
- `site/brand/`: logos for others to use (served at `/brand/`, referenced by no page): the transparent symbol `zero-logo.svg` (dark ring) and `zero-logo-light.svg`, their 512×512 RGBA renderings `zero-logo-transparent*.png` (regenerated by `node scripts/brand-png.mjs`, Node built-ins only) and the horizontal symbol plus word `zero-logo-horizontal*.svg`. `zero-logo.png` and `zero-symbol.png` stay as they are. Their use is governed by `TRADEMARK.md`, at the root of the repository. `test/brand.test.ts` checks them.
