# Distributed factory

The same factory on several machines of the person in charge, coordinated through a private GitHub repository.

- `src/machine.ts` and `src/coord/`: the distributed factory (`docs/adr/0007-fabrica-distribuida.md`), off unless the factory file has `distributed` (strict: `repository` `owner/name`, `heartbeatSeconds` at least 30, default 60, `leaseMinutes` at least 2 and three heartbeats, default 10, optional `machine`). `machineIdentity` keeps the machine's id in kv `machine:id` (name from `machine` or the host); `machineCapabilities` declares only `platform`, `box` and `engines`. `protocol.ts` (`CoordApi`, `CoordConflict`, `memoryCoord`) holds `claimJob` (create `claims/<job>`; a closing record, an unreadable claim or an expired holder is taken over only from the tip read, an expired holder returned as `takenFrom`), `stillHolds` (false for a closing record), `releaseJob` (a compare-and-swap of the claim to a closing record `{job, machine, name, at, released: true, status}`, never a delete, since GitHub deletes refs with no expected tip), `readClaimOf`, `probeCoord` (creates `probe/<id>`, checks that creating it again and moving it from a stale sha give `CoordConflict`, then deletes it), `heartbeat` (`machines/<id>`, public fields only) and `listMachines`; `github.ts` (`githubCoord`) maps it to refs `refs/heads/zero-coord/*` on empty-tree commits of the private coordination repository, 422 becoming `CoordConflict`, never Actions. `coordPass` (`pass.ts`, the daemon's `coordinate`, at most every `heartbeatSeconds`, the meter's `coord` pass, skipped during `githubHalt`, off in `once` runs unless `DaemonOptions.coord` is injected) probes the repository first, once per `distributed.repository` and a failed probe again at most once an hour (`PROBE_RETRY_MS`), keeping `{repository, at, ok, problem?}` in kv `coord:probe`, then beats and stores the list in kv `coord:machines`, which `factoryStatus` gives as `FactoryStatus.machines` only with `distributed`, shown as the `Máquinas:` block (`machineLine` in `src/format.ts`) of `formatStatus` and the panel summary. `joinFactory` in `app.ts` (`zero unirse <owner/repo>`, an injectable `CoordRepoCheck`) writes `distributed.repository` through `editConfig` only for a private repository it can read. Records read back are validated strictly (ids `[A-Za-z0-9-]`, ISO times, names without control characters). `coordReady` is true only with `distributed` and a passed probe of its current repository; the runner will rely on the protocol only then. The daemon does not claim jobs through the protocol yet.
